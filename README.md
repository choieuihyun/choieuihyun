## 개인 프로젝트

### [Personal Agent Harness](https://github.com/choieuihyun/Personal_Agent) — AI 오케스트레이션 골격

업무 효율화를 위한 AI 오케스트레이션을 구성하던 도중, 여러 프로젝트를 할 일이 생겨 오케스트레이션 이식을 편하게 하고싶어 만든 골격


- 어느 프로젝트를 하던 간에 직접 커스텀한 AI 오케스트레이션을 해당 도메인에 적용 가능하도록 모듈화.
- 파이썬 패키지로 설치 가능
- Maestro와 연계하여 개발 -> 테스트 자동화까지의 

Develop : 커맨드 하나가 서브에이전트를 순서대로 몰아 탐색 → 수정 → 빌드 → 런타임 검증까지 돌리고, 실패하면 분류하여 사람에게 보고합니다.
          **도구 권한은 프롬프트로 부탁하지 않고 설정 파일로 제한합니다.**

`Python` · `Shell` — 업무에서 쓰던 파이프라인을 프로젝트에 의존하지 않는 골격으로 추출

### [LogLens](https://github.com/choieuihyun/LogLens) — 안드로이드 로그 표준화

로그를 정해진 형식으로 찍은 후 편하게 필터링하여 볼 수 있도록 하는 로그 뷰어.
로그 형식을 읽어 필터링하며 두 컴포넌트는 서로의 코드를 참조하지 않고 **로그 한 줄 형식만 공유**합니다.
라이브러리 사용 시 AppDomain 파일에 프로젝트에 맞는 도메인 구조로 카테고리를 제작하여 필터링 가능합니다. 

`Python` · `Kotlin` · `.aar 배포` — 현재 업무 제품에 적용하여 테스트 중

### Floduler - 나도 계획좀 짜보자, 방탈출 시간표 만들기

- 방탈출러들은 기본 3연방, 4연방을 하며 타 지역으로 원정을 가기도 한다.
  이 때, 여러 팀으로 구성되는 경우 + 여러 테마를 하는 경우 각 팀이 겹치지 않고 비슷한 시간에 끝내기 위한 방탈출 시간표 짜기 프로젝트.
  빈자리 알림 받기도 추가 중.

#### [Floduler](https://github.com/choieuihyun/RoomEscapeScheduler) — Front

- FlodulerServer와 연계된 프론트
- 겹치지 않는 모든 조합을 계산해 대기 시간이 어디에 얼마나 생기는지 보여줍니다.
- Server를 통해 실제 방탈출 회차 불러오기가 가능하고, 이미지 혹은 시간 직접 입력으로도 시간대 입력이 가능합니다.
- 이미지 인식의 경우 예약 화면 캡처에서 회차 시간을 읽어오는데, **인식이 브라우저 안에서 돌아 이미지가 서버로 나가지 않습니다.** 정적 호스팅으로 배포됩니다.

`TypeScript` · `PaddleOCR(브라우저)` · `GitHub Pages`

#### [FlodulerServer](https://github.com/choieuihyun/RoomEscapeServer) — BackEnd

- 위의 Floduler 연계된 서버입니다.

테스트용 매장 10곳의 응답 형식이 HTML, JSON, POST, 조각으로 제각각이라 어댑터로 흡수했고,
**어댑터를 쓰기 전에 매장별 요청과 판정 근거를 먼저 문서로 적었습니다.**

`Kotlin` · `Spring Boot` · `PostgreSQL` · `Docker` · `Caddy` — 오라클 클라우드에서 운영 중

### [QuantTrading](https://github.com/choieuihyun/QuantTrading) — 종목 발굴 파이프라인

투자를 하되, 전세계적으로 유명하고 승률이 높은 방법 패턴 기법을 적용하여 차트 기반 종목을 발굴해보고, 내가 생각하는 차트 패턴을 증명해보기 위한 프로젝트
각 패턴을 기준으로 이전에 샀다면 최고, 최저, 평균 수익률이 얼마인지 등을 검증하여 부자가 되어보고자 만들어본 프로젝트


시세와 공시 재무를 모아 패턴별 후보를 추리고, 과거 시점 매수를 가정한 백테스트로 검증합니다.
스케줄 시각을 시장 구조에서 역산했습니다 — 장중에는 일봉이 미완성이라 거래량 비율이 왜곡되고, 그 값을 쓰는 패턴이 전부 탈락하기 때문입니다.

`Python` · `Next.js` · `GitHub Actions` · `Firestore` · `DART 공시 연동`
